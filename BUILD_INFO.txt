Application changes:
- Group creation now calls the existing production create_group_chat RPC, then applies visibility and avatar settings through rim_group_update_settings. The unsupported group-username field was removed instead of pretending it was persisted.
- Public groups are discoverable to authenticated users through a narrowly scoped SELECT policy. Joining uses rim_group_join_public, which checks group visibility, E2E state and permanent group bans; private conversation messages and member lists remain protected.
- Search result navigation is delegated from the stable results root so users, channels, messages and public groups remain clickable after asynchronous rendering.
- Feed publish click now resolves the current Supabase publisher at click time rather than retaining the obsolete local-only function reference.
- Chat bootstrap placeholders no longer emit misleading “module is loading” notices when the modular chat list already owns rendering.
- Settings now includes a “Мой профиль” entry. Birth date is stored separately in profile_private_details with owner-only RLS; it is not exposed through the public profiles table.
- Eligible secret direct chats expose the E2E verification action in chat information. Group E2E controls remain restricted to private groups.
- Zladen now answers /help <command> with command-specific descriptions, including group custom commands and aliases. The handler skips E2E-required, pending and secret conversations. The group console also explains its quick-command presets.
- Music render failures now show an actionable error panel and retry control instead of leaving a blank section.
- Browser asset cache key is 4.1.8.183-release. Existing Signal SDK 14.7.0, idb 8.0.3 and esbuild 0.27.0 remain pinned.

Verification:

- Live acceptance on two authenticated Android accounts is not simulated by unit tests. E2E group exchange, actual audio playback, Telegram OAuth, and the complete UI flow still require device-level verification.

Known scope limits:
- This iteration does not claim full Iris feature parity. It improves Zladen command discoverability while preserving the existing moderation, triggers, economy, games, polls, reminders, clans, aliases and custom-command modules.
- Profile birth date is private to the account owner by default; public birthday visibility is intentionally not implemented.
