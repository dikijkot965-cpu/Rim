# Злыдня — команды Iteration 141

## Игры и прогресс

- `/daily` — ежедневная награда, один раз за календарный день UTC.
- `/quiz` — вопрос дня с вариантами ответа.
- `/answer 2` — ответ на викторину; одна попытка в день, за верный ответ начисляется 20 жетонов.
- `/economy_top` — рейтинг балансов.

Награды фиксированные. Жетоны не являются деньгами, не выводятся и не используются для ставок.

## Магазин и торговля

- `/shop` — каталог.
- `/buy badge_bronze 2` — купить предметы из каталога.
- `/inventory` — свой инвентарь.
- `/market` — активные объявления участников.
- `/market_sell badge_bronze 1 75` — выставить один предмет по цене 75 жетонов за штуку.
- `/market_buy UUID 1` — купить указанное количество из объявления.
- `/market_cancel UUID` — снять собственное объявление и вернуть остаток предметов.

Покупка на рынке выполняется одной транзакцией: объявление блокируется, баланс покупателя списывается, продавцу начисляется сумма, предмет переходит покупателю, операция записывается в ledger. Собственные объявления покупать нельзя.

## Автоматизация групп

Команды доступны администраторам группы:

- `/trigger list` — список триггеров.
- `/trigger add приветствие | contains:привет | reply:Привет!` — ответ на сообщение, содержащее фразу.
- `/trigger add активность | starts_with:доброе утро | grant:10` — до 10 жетонов за совпадение, не чаще одного раза на участника в сутки для этого триггера.
- `/trigger join_add вступление | reply:Добро пожаловать! ID: {user_id}` — ответ при вступлении нового участника.
- `/trigger del 1a2b3c4d` — удалить триггер по уникальному префиксу ID из списка.

Условия ограничены `contains`, `starts_with`, `equals`; действия — ответом Злыдни или ограниченной наградой. Исполняемый пользователем код не принимается. На одно сообщение обрабатывается не более трёх триггеров. Триггеры не работают в беседах с обязательным E2E.
